# ♻️ Reciclo PE - Sistema de Gestão de Resíduos Têxteis

Projeto interdisciplinar desenvolvido para o curso de Análise e Desenvolvimento de Sistemas da UNINASSAU. O sistema visa auxiliar na gestão e rastreabilidade de resíduos gerados pelo Polo de Confecções do Agreste.

## 📋 Funcionalidades
- **Cadastrar Unidades:** Registro de fábricas, oficinas e cooperativas.
- **Listagem Filtrada:** Visualização de unidades por cidade (Toritama, Caruaru, Santa Cruz) ou tipo.
- **Cálculo de Resíduos:** Monitoramento do volume de descarte em kg.
- **Persistência de Dados:** Simulação de banco de dados em memória (Dicionários Python).

## 🚀 Como rodar o projeto
1. Certifique-se de ter o Python 3.x instalado.
2. Clone este repositório ou baixe o arquivo `.py`.
3. Execute no terminal:
   ```bash
